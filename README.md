# English-word-test-tool
英単語一覧のCSVファイルを取り込むことでランダムに英単語テストのプリントが作成でき、印刷までスムーズに行えるツールです。

## 目的
英語の勉強で定期的に自分がどれほど単語を理解しているのか調べたいと感じていた。
世の中にそういったツールは溢れているものの、自分の個人情報を入力する機会はできるだけ減らすに越したことはないし、何より広告が煩わしかったり不必要な機能で本来の便利さが利用者によっては不便さになっている。自分でテストに出る単語を自由に変更できたら楽だと考えた。またstremalitの扱いに慣れる目的もあった。

## 所感
かなりシンプルなUIながらかなり快適な操作性を実現できたと感じている。
